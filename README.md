# Modified Telegram

Улучшенный клиент Telegram с дополнительными возможностями.

## Возможности (в разработке)

- Вход по номеру телефона или QR-коду
- Левое меню настроек
- Система команд
- ИИ автоответ (вкл/выкл)
- Редактор пользовательских команд (JavaScript / Python / Lua)
- Режим скрытности (скрытие онлайна)
- Настройка ИИ (свой API + бесплатные варианты)

## Статус

Проект в стадии начальной разработки.
